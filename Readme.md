
# 🔐 Login Container

A clean and lightweight **Python Flask login system** built for learning, experimentation, and future web-dashboard projects.

## ✨ Features

* 🔑 User login system
* 🧭 Dashboard interface
* 🎨 Clean responsive styling
* 🐍 Built with Python & Flask
* 💾 SQLite database support
* 📁 Simple and easy-to-understand project structure
* 🚀 Ready for further development and deployment

## 🛠️ Tech Stack

* **Python**
* **Flask**
* **SQLite**
* **HTML5**
* **CSS3**
* **Git & GitHub**
* **Termux** for development

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/pussymechanic1-stack/Login-container-.git
cd Login-container-
```

### 2. Install Flask

```bash
pip install flask
```

### 3. Start the application

```bash
python app.py
```

The application will normally be available at:

```text
http://127.0.0.1:5000
```

## 🔐 Database

The project uses **SQLite** for local user data.

The database file is intentionally excluded from Git using `.gitignore`:

```text
users.db
```

This prevents local database data from being accidentally uploaded to GitHub.
